# IBM Plex Sans — temporary visual experiment

Unmodified official Google Fonts v23 WOFF2 files, downloaded 2026-10-08. Licensed under SIL Open Font License 1.1; see OFL.txt. No commercial fonts are included.

- Latin, 45,712 bytes: https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYY.woff2
- Latin Extended, 30,964 bytes: https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxQKYbABA.woff2
- Official CSS source: https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500&display=swap
- License source: https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt

Google Fonts serves the same variable WOFF2 for both requested weights. The two script subsets support both Regular 400 and Medium 500, so separate duplicate weight files are unnecessary. CSS exposes only 400–500. The Latin subsets cover the existing ES / DE / EN content. No Plex Mono was added; intentional system monospace stays unchanged.

Both files are self-hosted with relative URLs, compatible with GitHub Pages project paths and direct local HTML. Total font payload: 76,676 bytes.
